# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/amaury-molina/hookrelay/security/advisories/new).
Do not open a public issue.

You can expect an acknowledgement within 72 hours.

## Scope

HookRelay is a portfolio project. The public demo only accepts synthetic
webhooks and stores no personal data. Secrets are managed with Cloudflare
Worker secrets and GitHub Actions secrets and are never committed.
